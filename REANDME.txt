== 虛擬環境 ==

** 虛擬環境操作(僅Windows適用) **
建立: python -m venv venv
啟動: .\venv\Scripts\activate
退出: deactivate


** 需要安裝的模組 **

# OpenCV（含人臉辨識模組）、Flask、NumPy
python -m pip install flask flask-socketio opencv-contrib-python numpy 


** 如果出現錯誤: AttributeError: module 'cv2' has no attribute 'face' **
1. 先卸載現有的 OpenCV
pip uninstall opencv-python opencv-contrib-python
2. 安裝包含 face 模組的版本
pip install opencv-contrib-python

** 如果 venv 無法啟動 (powershell) **
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

** Git 使用者資訊設定 **
git config --global user.email "you@example.com"
git config --global user.name "Your Name"
